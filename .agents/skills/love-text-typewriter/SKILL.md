# Love Text Typewriter

Implement a delicate typewriter effect for romantic texts.

## Steps

1. Wrap the text elements (letters or words) using a library like SplitText or pure JS.
2. Animate the opacity of each character sequentially.
3. Keep the timing relatively slow and smooth to convey emotion.
4. Add a blinking cursor with a soft pink or gold color.
