# Audio Player Romantic

Add an auditory dimension to the romance website.

## Steps

1. Create a minimalist toggle button (e.g., a spinning vinyl record or a pulsing heart).
2. Use the HTML5 `<audio>` API to play a romantic instrumental track.
3. Implement fade-in logic when the user presses play (gradually increasing volume) to avoid sudden loud noises.
4. Ensure autoplay policies are respected by requiring a user interaction to start the music.
