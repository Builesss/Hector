# React Project Setup

This skill guides the initialization of a React project.

## Steps

1. Create a new project using Vite: `npm create vite@latest . -- --template react-ts` (if TypeScript is desired) or `react`.
2. Set up the directory structure: create `src/components`, `src/pages`, `src/assets`, `src/styles`, and `src/hooks`.
3. Configure global CSS files (e.g., `index.css`) with base romantic typography (e.g., Playfair Display or cursive fonts) and CSS variables for the color palette.
4. Clean up default Vite boilerplate to prepare a blank canvas.
