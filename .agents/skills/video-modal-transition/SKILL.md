# Video Modal Transition

This skill guides you to build a romantic video presentation.

## Steps

1. Create a play button with a soft glow effect.
2. On click, expand a modal with a smooth scale and fade transition using CSS or GSAP.
3. Apply a dark overlay with a slight blur (backdrop-filter) behind the video to focus the attention.
4. Animate the video container revealing from the center outward.
