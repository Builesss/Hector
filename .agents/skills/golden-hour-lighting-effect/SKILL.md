# Golden Hour Lighting Effect

Simulate a romantic sunset or warm lighting effect on the page.

## Steps

1. Apply a CSS overlay with a linear or radial gradient using warm colors (`#ffdf00`, `#ff8c00`).
2. Use `mix-blend-mode: overlay` or `soft-light` on the images.
3. Add a subtle text-shadow with a golden hue to headings.
4. Optionally animate the gradient position slowly to simulate the passage of time or moving sunlight.
