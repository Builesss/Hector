# Parallax Scroll Romance

Add depth to the website using parallax.

## Steps

1. Set up container elements with `overflow: hidden`.
2. Apply a y-axis translation to the inner images based on the scroll position.
3. Use a library like GSAP ScrollTrigger or simple CSS `transform: translateZ` techniques.
4. Ensure the movement is subtle and fluid, enhancing the storytelling without being distracting.
