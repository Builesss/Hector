# Floating Hearts Background

Create a magical ambiance with floating background elements.

## Steps

1. Generate multiple SVG heart elements dynamically or use a Canvas context.
2. Apply random `left` positions and `animation-delay` to each heart.
3. Animate them moving from the bottom to the top of the screen while slightly rotating and changing opacity.
4. Ensure `pointer-events: none` so they don't block user interaction.
