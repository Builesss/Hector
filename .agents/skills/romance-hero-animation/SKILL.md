# Romance Hero Animation

This skill provides guidelines for creating a stunning hero section for a romance website.

## Steps

1. Structure the HTML with a full-screen `min-h-screen` section.
2. Use a soft, romantic background image or gradient (e.g., `#ffb6c1` to `#ffc0cb`).
3. Apply GSAP or CSS animations to softly fade in the title text from the bottom.
4. Implement a subtle floating particle effect (like hearts or light dust) in the background.
